## Rules
1. Work on your own branch.
2. Don't push directly to main.
3. Pull/merge main regularly.
4. Don't modify another person's module without telling them.
5. Never commit API keys or `.env`.
6. Keep module inputs/outputs consistent with MODULE_CONTRACTS.md.
7. Test before merging.
